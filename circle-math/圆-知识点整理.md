## 一、基础知识点

### 1. 圆的认识 🟢
- **圆心 O**：决定圆的**位置**；**半径 r**：决定圆的**大小**；**直径 d**：通过圆心、两端在圆上的线段。
- 同圆（或等圆）中：有无数条半径、无数条直径，长度都相等；**d = 2r，r = d ÷ 2**。
  - 易错：判断"直径是半径的 2 倍"——**错**，缺少"在同圆或等圆中"。
- 用圆规画圆：定点（圆心）、定长（半径＝两脚间距）、旋转一周。
- 圆是**轴对称图形**，**每条直径所在的直线**都是对称轴，有**无数条**。（注意：对称轴是"直线"，不是"直径"。）
- 圆是**曲线图形**；长方形里画最大的圆，直径＝长方形的**宽**。

| 典型例题 | 难度 |
|---|---|
| 圆规两脚间距 3 cm，画出的圆直径是多少？（6 cm） | 🟢 |
| 判断：所有直径都相等。（×，要在同圆或等圆中） | 🟢 |
| 在长 10 cm、宽 6 cm 的长方形中画一个最大的圆，半径是多少？（3 cm） | 🟡 |
| 把一张圆形纸对折两次，两条折痕的交点是什么？（圆心） | 🟢 |

### 2. 圆周率 π 🟢
- **π = 圆的周长 ÷ 直径**，任何圆都一样，是一个**固定的数**。
- π 是**无限不循环小数** 3.1415926535…，计算时一般取 **3.14**。
  - 易错：判断"圆周率就是 3.14"——**错**，3.14 只是近似值。
- 历史小故事：
  - **阿基米德**（古希腊，约公元前 3 世纪）：用圆内接、外切**正 96 边形**算出 3.1408 < π < 3.1429（即 223/71 < π < 22/7）。
  - **刘徽**（三国·魏）：发明**"割圆术"**，"割之弥细，所失弥少"，算到 3.14（"徽率"），后又得 3.1416。
  - **祖冲之**（南北朝）：算出 **3.1415926 < π < 3.1415927**，领先世界近千年；提出约率 **22/7**、密率 **355/113**。

| 典型例题 | 难度 |
|---|---|
| 大圆的周长÷直径 与 小圆的周长÷直径 比，哪个大？（一样大，都是 π） | 🟢 |
| 圆的周长是直径的（ ）倍：A.3　B.3.14　C.π（C） | 🟢 |
| 第一个把 π 精确到小数点后 7 位的是谁？（祖冲之） | 🟢 |

### 3. 圆的周长 🟢
- **C = πd = 2πr**；反求：**d = C ÷ π，r = C ÷ π ÷ 2**。
- 推导：**滚动法**（圆在直尺上滚一周）、**绕绳法**（绳子绕圆一周再拉直量），发现周长总是直径的 3 倍多一些 → 就是 π 倍。
- 车轮问题：**车轮转 1 圈，前进 1 个周长**；路程 = 周长 × 圈数。
- 常用值（建议背）：3.14×2=6.28，×3=9.42，×4=12.56，×5=15.7，×6=18.84，×7=21.98，×8=25.12，×9=28.26；3.14×16=50.24，×25=78.5，×36=113.04，×49=153.86，×64=200.96，×81=254.34。

| 典型例题 | 难度 |
|---|---|
| r = 5 cm，求周长。（31.4 cm） | 🟢 |
| 周长 18.84 cm，求半径。（3 cm） | 🟢 |
| 车轮直径 0.5 m，转 100 圈前进多少米？（157 m） | 🟡 |
| 钟面分针长 10 cm，走一圈针尖走过多少厘米？（62.8 cm） | 🟡 |

### 4. 圆的面积 🟢
- **S = πr²**（r² 表示 r×r，不是 r×2！）
- 推导：把圆平均分成 8、16、32……份，拼成**近似的长方形**；份数越多越接近长方形。
  长 ≈ 周长的一半 = **πr**，宽 ≈ **r**，所以 S = πr × r = πr²。
  - 拼成后：**面积不变，周长变了**（长方形周长 = 圆周长 + 2r）。
- 知道 d 或 C 求面积：**先求 r** 再代入。

| 典型例题 | 难度 |
|---|---|
| r = 4 cm，求面积。（50.24 cm²） | 🟢 |
| d = 10 dm，求面积。（78.5 dm²） | 🟢 |
| 周长 12.56 m，求面积。（r=2，12.56 m²） | 🟡 |
| 圆拼成近似长方形，长方形周长比圆周长多 6 cm，求圆面积。（2r=6，r=3，28.26 cm²） | 🟡 |

### 5. 圆环 🟡
- **S环 = πR² − πr² = π(R² − r²)**（R 外圆半径，r 内圆半径）。
  - 易错：写成 π(R − r)²。
- 环宽 = R − r。

| 典型例题 | 难度 |
|---|---|
| 外圆半径 5 cm，内圆半径 3 cm，求圆环面积。（50.24 cm²） | 🟢 |
| 外直径 20 cm，内直径 12 cm 的圆环面积。（200.96 cm²） | 🟡 |
| 外圆周长 31.4 cm，内圆半径 2 cm，求圆环面积。（65.94 cm²） | 🟡 |

### 6. 扇形 🟡
- 扇形由**两条半径和一段弧**围成，顶点在圆心的角叫**圆心角**。
- 扇形占圆的 **n/360**：扇形面积 = πr² × n/360；弧长 = 2πr × n/360。
- 扇形周长 = 弧长 + **2r**。
- 扇形大小与**半径**和**圆心角**都有关。

| 典型例题 | 难度 |
|---|---|
| 圆心角 90°、半径 4 cm 的扇形面积。（12.56 cm²） | 🟢 |
| 扇形面积是圆面积的 1/6，圆心角多少度？（60°） | 🟢 |
| 半径 6 cm、圆心角 120° 的扇形面积。（37.68 cm²） | 🟡 |

### 7. 半圆（最容易错）🟡
- **半圆周长 = 圆周长的一半 + 直径 = πr + 2r = 5.14r**。
  - 易错：只算 πr，**漏掉直径**！"半圆的周长是圆周长的一半"——**错**。
- 半圆面积 = πr² ÷ 2。

| 典型例题 | 难度 |
|---|---|
| 直径 10 cm 的半圆，周长？（15.7 + 10 = 25.7 cm） | 🟡 |
| 半径 4 cm 的半圆，面积？（25.12 cm²） | 🟢 |

## 二、圆与正方形

### 1. 外方内圆（正方形里最大的圆）🟡
- 圆直径 = 正方形边长 a，r = a/2。
- 正方形 = (2r)² = **4r²**，圆 = **3.14r²**，空白 = **0.86r²**。
- **圆 ÷ 正方形 = π/4 ≈ 78.5%**（不管多大都一样）。

### 2. 外圆内方（圆里最大的正方形）🔴
- 正方形对角线 = 圆直径 = 2r，正方形可分成 4 个直角边为 r 的等腰直角三角形：**正方形面积 = 2r²**。
- 圆 = 3.14r²，空白 = **1.14r²**；圆 ÷ 正方形 = π/2 ≈ 1.57。

### 3. 周长与面积的"冠军" 🟡
- **周长相同**：圆面积最大 > 正方形 > 长方形。
- **面积相同**：圆周长最短。

| 典型例题 | 难度 |
|---|---|
| 边长 10 cm 的正方形内画最大的圆，求圆面积。（78.5 cm²） | 🟢 |
| 正方形面积 20 cm²，里面最大的圆面积？（r²=5，15.7 cm²） | 🔴 只知 r² |
| 半径 5 cm 的圆内画最大的正方形，面积？（2×25=50 cm²） | 🟡 |
| 圆内最大正方形面积 18 cm²，求圆面积。（2r²=18，r²=9，28.26 cm²） | 🔴 |
| 周长相等的长方形、正方形、圆，谁面积最大？（圆） | 🟢 |

## 三、拔高题与易错点

| 考点 | 要点 | 典型例题 | 难度 |
|---|---|---|---|
| 半圆周长漏直径 | 半圆周长 = πr + 2r | 直径 10 cm 半圆周长 25.7 cm | 🟡 |
| 半径扩大 n 倍 | d、C 都扩大 n 倍，**S 扩大 n² 倍** | 半径扩大到 3 倍，面积扩大到 9 倍；r 比 2:3 → 面积比 4:9 | 🟡 |
| 周长增加 ↔ 半径增加 | 周长增加 6.28 → 半径增加 1 | 周长增加 6.28 cm，半径增加多少？（1 cm） | 🟡 |
| 只知 r² | 不求 r，整体代入 r² | 正方形面积 16，求内切圆（r²=4，12.56） | 🔴 |
| 树叶形（重叠/等积） | 叶 = 2 个 1/4 圆 − 正方形 = **0.57a²** | 正方形边长 10 cm，树叶面积 57 cm² | 🔴 |
| 割补 / 平移 | 把弯曲的阴影移到一起拼成规则图形 | 两个边长 4 的正方形中的阴影 = 16 | 🔴 |
| 弯月形（希波克拉底月牙） | 两个小半圆 = 大半圆，去掉公共部分 → **月牙 = 三角形** | 大半圆半径 6，两个月牙面积和 36 | 🔴 |
| 跑道问题 | 一圈 = 2 条直道 + 一个整圆；相邻跑道起跑线相差 **2π×道宽**（跑一整圈时） | 直道 100 m、弯道直径 60 m，一圈 388.4 m；道宽 1.25 m，前移 7.85 m | 🔴 |
| 滚动问题 | 圆心走过的路 ÷ 自身周长 = 圈数；绕外侧滚：**(R+r)/r 圈** | 硬币绕同样大的硬币滚一周自转 **2 圈** | 🔴 |
| 钟表扫面积 | 分针 = 半径，按圆心角/时间算份数 | 分针 10 cm，12→3 扫过 78.5 cm² | 🟡 |
| 羊吃草 | 绳长为半径，绕过墙角时半径变短 | 3 m 正方形羊圈角上拴 4 m 绳：12π + 0.5π = 39.25 m² | 🔴 |
| 组合图形周长 | 只描外边线：曲线段 + 直线段，**不要把面积公式混进去** | 长方形 + 半圆的周长 | 🟡 |
| 单位/概念混淆 | 周长和面积不能比大小 | "半径 2 cm 的圆周长与面积相等"（×） | 🟢 |

### 跑道起跑线原理（拓展课"确定起跑线"）
每条跑道直道一样长，只有弯道不同。弯道合起来是一个整圆，相邻两道直径差 2×道宽，
所以周长差 = π × 2 × 道宽。跑 400 m（一整圈）：前移 2π×道宽；跑 200 m（半圈弯道）：前移 π×道宽。

## 四、建议学习顺序（约 7 次课）
1. 认识圆（画圆、各部分关系、对称）
2. 认识 π（动手量 + 历史故事）
3. 周长（公式 + 反求 + 车轮 + 半圆）
4. 面积（推导 + 已知 d / C 求 S + 扩大倍数）
5. 圆环与扇形
6. 圆与正方形（4r²、2r²、0.86r²、1.14r²、0.57a²）
7. 拔高挑战（阴影、跑道、滚动、羊吃草）→ 综合测验 → 错题回炉
